# Language

The team prompts Kiro in French. Everything that ends up in the repository or in front of users is in English.

| What | Language |
|---|---|
| Prompts to Kiro, team chat | French |
| Code, identifiers, comments | English |
| Commit messages, PR titles and descriptions | English |
| UI text, CLI output, hook messages | English |
| Specs, steering, README, docs, journal | English |

## How to write

- When a prompt is in French, answer in French in the chat, but write all generated files in English.
- Keep sentences short and plain. No jargon in user-facing text.
- Comments explain why, not what. Do not comment the obvious.
- Commit messages follow Conventional Commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`, `spec:`, `steer:`).
- Organ names (Séance, Grimoire, Ledger) may keep their French spelling as proper nouns.
